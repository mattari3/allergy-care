# ナッツアレルギー記録 PWA サンプル

スマホブラウザで使える、ナッツ系食品（ピーナッツ、カシューナッツ、くるみ等）の摂取記録・症状写真・保護者向け掲示板のPWAサンプルです。

## 反映した修正

- 患者ID・患者名によるログイン画面を追加
- サマリー機能を削除
- アレルギー食品をナッツ系に変更
- 設定画面でログインユーザ情報（患者ID、患者名、保護者名、メール、ログイン方式）を確認・編集可能に変更

## 使い方

1. `index.html` をブラウザで開く
2. 患者ID・患者名を入力してログイン
3. 記録・掲示板・設定を確認

## GitHub Pagesで公開する場合

このフォルダ内のファイルをリポジトリ直下に置き、Settings > Pages で公開してください。

## 本番化で差し替える部分

- デモ認証 → Firebase Authentication / 独自認証
- localStorage → Firestore
- 写真のbase64保存 → Firebase Storage
- 掲示板投稿 → Firestore Security Rulesで本人・管理者権限を制御
