# ナッツアレルギー記録 PWA サンプル

スマホブラウザで使える、ナッツ系食品の摂取・症状記録用PWAサンプルです。

## 今回の主な修正

- 「保護者掲示板」画面を削除
- 下部ナビゲーションから掲示板を削除
- 「詳細記録」画面から登録済み情報を編集できる機能を追加
- 「詳細記録」画面から登録済み情報を削除できる機能を追加

## 使い方

1. `index.html` をブラウザで開く
2. 患者ID・患者名でログイン
3. 記録一覧またはカレンダーから詳細記録を開く
4. 詳細記録画面の「編集する」または「削除する」を使用

## 本番化で差し替える部分

- デモ認証 → Firebase Authentication など
- localStorage → Firestore など
- 写真のbase64保存 → Firebase Storage など
