# ナッツアレルギー記録 PWA サンプル

スマホブラウザで使える、ナッツ系食品の摂取・症状記録用PWAサンプルです。

## 今回の主な修正

- 掲示板機能を削除
- ホーム画面の「よく使うタグ」を削除
- ホーム画面の「症状記録」ボタンを削除
- 詳細記録から登録情報を編集・削除できる機能を追加
- カレンダーに食品アイコンを表示
- 食材選択を「ピーナッツ、カシューナッツ、くるみ、ヘーゼルナッツ、マカダミアナッツ、その他」に限定
- 「その他」選択時に任意の食材名を入力可能

## 使い方

1. `index.html` をブラウザで開く
2. 患者ID・患者名でログイン
3. 記録・カレンダー・設定画面を確認

## 本番化で差し替える部分

- デモ認証 → Firebase Authentication など
- localStorage → Firestore など
- 写真のbase64保存 → Firebase Storage など
